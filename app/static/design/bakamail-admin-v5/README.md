BakaMail 管理后台，浅色纯色版：近乎白的晴空蓝底、白色大圆角卡片，颜色又轻又干净，没有线条，可爱又治愈。

## 语气
- 简体中文，直接说事。按钮动词开头（“保存设置”），进行中写“正在保存…”，完成用通知说“设置已保存”。
- 错误说清怎么办：“邮箱地址格式不正确”。不道歉，不用感叹号，不用 emoji。
- 读不到数据写“未提供”，不写 0；空列表一句话：“还没有保存的草稿”。
- 页面上不写功能解释，只留下一步要做的事需要的信息。

## 颜色
- 底 `milk`，卡片 `surface`；强调是 `sky` 一族：填充 `sky-100` 到 `sky-300`，文字和链接 `sky-700`。
- **颜色克制**：整屏以白、浅蓝和一个强调色为主，同一屏的粉彩不超过两种；颜色都是明亮的浅色，不发灰、不发闷，大面积只用白和最浅的蓝。
- 一种意思一种粉彩：成功 `mint`、留意 `peach`、危险 `pink`、“新” `butter`（每屏一两处）、角色和小标签 `lilac`。每种粉彩有 `-100` 底、`-300` 气泡和 `-700` 文字三档，文字都不低于 4.5:1。
- 文字 `ink`，次要 `ink-soft`。不再有 `text-faint`。

## 形状
- **没有线条**：不画边框、分隔线、网格线、轮廓。分开靠颜色深浅（卡片白、底奶蓝、块淡蓝）和柔和的影子（`shadow-card`、`shadow-float`）。
- **唯一保留的线**是键盘聚焦的 2px 实色轮廓（`sky-700`），为了能看见焦点。折线图的数据线也保留。
- **很圆**：控件 18、卡片 28、大卡片和弹窗 36，按钮、徽标、开关、通知、分段选择都是胶囊。
- **软软的**：按钮底部有 3px 的实色台阶，按下消失；图标放在圆气泡里，悬停时弹一下；品牌方块微微倾斜。

## 版式
字体 `font-sans`（系统圆体）。数值 `display`，标题 `title` / `heading`，正文 `body`，标签 `label`，说明 `caption`，小标签 `tag`。输入框统一 50px 高；手机上 16px 字。卡片之间 `space-5`，内边距 `space-6`。桌面端侧栏与右侧大容器上下边界同高同位。

## 动效
- 缓动 `ease` 和带回弹的 `spring`；只做透明度和位移，结束后不留变换。
- 每张卡片、每块文字、每行数据出现时依次入场，相邻错开约 70ms。
- 加载：右侧容器还没出现时才显示三颗小球，旧内容先淡出，容器出现就淡出收起，两者不同时出现。
- 选中的淡蓝胶囊点击即平移到新菜单项，不等页面加载。
- “减少动态效果”或低性能模式下，所有动画关闭。

## 图标
24 视口、1.8px 描边、圆头、无填充，颜色用 `sky-700`（或所在粉彩的 `-700`），放在淡色圆气泡里。

## 组件
Panel、StatCard、Button、Field、Badge、NavRail、RangeTabs、TrendChart、Table、Dialog、Toast、EmptyState、Loader。

## 与线上后台的差别
线上后台以浅蓝线条和线条动画为特色；这一版去掉线条、改用明亮的浅色，是新的提议，线上还没有采用。预览是静态样式，不是可运行的组件包。
